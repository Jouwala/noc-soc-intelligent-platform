## 目标（第二轮，不在第一轮做）

1. **统一数据访问入口**：先只读查询，后写入任务；新入口放在
   `apps/my_app/backend/` 里面，不在仓库根建一个靠 `sys.path` 拼接的
   `integrations/`。**未完成。**
2. **逐表盘点**：每一张表、每一个文件库的写方与读方盘完后，把上面「待确认」
   逐行改成事实。**未完成。**
3. 外部系统客户端仍放在现有包内，补超时、重试、错误类型和健康检查。**未完成。**
4. 会访问外部系统的测试加上 `live` 标记，并在 `apps/my_app` 跑出离线测试基线，
   然后 CI 才加入 `pytest -m "not live"`。**未完成。**

## 处理三张本地权威表的规矩

- 迁移用 `ops/deploy/local_authority_tools.py check/migrate --source <旧app.db> --target <新app.db>`，
  不要直接拷贝正在被生产打开的 `app.db` 文件。
- 三张表里包含生产凭据：只放在 02 本机数据库，不 `git add`；调度器保持关闭，
  不跑采集，不发信，不登录 WhatsApp；不把「复制了 credentials」说成
  「副本没有生产凭据」——库里有，只是不允许拿它们去连上游。
